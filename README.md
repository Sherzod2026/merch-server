# Контроль мерчендайзеров

Простая программа: мерчендайзер входит со своим логином, нажимает «АКТИВИРОВАТЬ» — и администратор видит его на карте в реальном времени, а также маршрут за любой день.

## Что внутри
- 2 администратора (`admin1`, `admin2`) и 27 мерчендайзеров (`merch01` … `merch27`).
- Пароли создаются автоматически при первом запуске и сохраняются в файл `data/credentials.csv` (открывается в Excel).
- Администратор может изменить имя и пароль любого мерчендайзера (кнопка ✎ в списке).
- Внешние пакеты не нужны — только Node.js 18 или новее.

## Запуск
```
node server.js
```
Откройте `http://localhost:3000`. Порт можно изменить: `PORT=8080 node server.js`.

## Важно: нужен HTTPS
Телефоны отдают геолокацию только сайтам с адресом `https://`. Поэтому для работы с мерчендайзерами программу нужно разместить на сервере с доменом и сертификатом.

**Самый простой вариант — VPS (любой, от 3–5 $ в месяц) + Caddy:**
1. Установите Node.js и Caddy на сервер, скопируйте папку программы.
2. Запустите программу как службу (например, через `pm2 start server.js`).
3. В файле `/etc/caddy/Caddyfile` укажите:
   ```
   merch.ваш-домен.uz {
       reverse_proxy localhost:3000
   }
   ```
   Caddy сам получит HTTPS-сертификат.

**Для быстрой проверки без сервера:** запустите программу на компьютере и выполните
`cloudflared tunnel --url http://localhost:3000` — появится временный адрес `https://…trycloudflare.com`, его можно открыть на телефоне.

## Как пользоваться
**Мерчендайзер:** открывает сайт на телефоне → входит → нажимает «АКТИВИРОВАТЬ» → разрешает доступ к местоположению. Страницу нужно держать открытой. В конце дня — «ОСТАНОВИТЬ».
Сайт можно установить на телефон как приложение (с иконкой «Мерч Контроль»):
- Android (Chrome): меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- iPhone (Safari): кнопка «Поделиться» → «На экран „Домой“».

Для полноценной работы с выключенным экраном используйте мобильное приложение из папки `merch-app`.

**Администратор:** входит → видит всех на карте:
- 🟢 активен и на связи (точка не старше 5 минут)
- 🟠 активен, но точки не приходят
- ⚪ неактивен

Нажмите на мерчендайзера — откроется его маршрут за выбранную дату: время начала и конца, пройденные километры, каждая точка со временем.

## Ограничения
Это веб-программа (сайт), а не приложение из Play Market. Если мерчендайзер закроет браузер или телефон надолго заблокирует экран, отправка местоположения остановится — администратор увидит оранжевый статус «нет связи». Если пропала сеть, точки сохраняются в телефоне и отправляются позже.

## Где хранятся данные
- `data/users.json` — пользователи (пароли хранятся в зашифрованном виде)
- `data/points/ГГГГ-ММ-ДД.ndjson` — точки маршрутов по дням
- `data/credentials.csv` — первоначальные логины и пароли (после раздачи сотрудникам лучше удалить с сервера)

Для резервной копии достаточно копировать папку `data`.
